Apa Itu Pemrograman?

Pemrograman adalah proses membuat perintah menggunakan bahasa komputer untuk menghasilkan aplikasi, website dan program.

HTML

Digunakan untuk membuat struktur website.

CSS

Digunakan untuk memperindah tampilan website.

JavaScript

Digunakan untuk membuat website interaktif.
