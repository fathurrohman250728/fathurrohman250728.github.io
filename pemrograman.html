Apa Itu Pemrograman?

Pemrograman adalah proses memberikan instruksi kepada komputer untuk menjalankan tugas tertentu.

HTML

Digunakan untuk membuat struktur halaman website.

CSS

Digunakan untuk mengatur tampilan dan desain website.

JavaScript

Digunakan untuk membuat website lebih interaktif.
